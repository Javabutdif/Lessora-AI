# Spec: client history tab

## Purpose

Provide a dedicated History tab in the client application (Expo React Native) that allows users to view, search, and navigate their previously generated lesson plans.

## Scope

- **In Scope:**
  - Create a new `HistoryScreen.tsx` that displays a list of all lesson plans generated by the user.
  - Implement a search bar at the top of the history screen to filter plans by title, subject, or grade level.
  - Update `BottomTabBar.tsx` to add/replace a tab for History next to the Generate button.
  - Fetch history data from the existing `/ai/lesson-plan/history` endpoint.
  - Implement pull-to-refresh to reload the history.
  - Clicking on a history card will navigate the user to the existing `Preview` screen of that lesson plan.
  - Maintain the existing visual theme (navy, electric blue, soft gray, card elements).
  - Implement a highly responsive custom modal-based grade selector in `GeneratePlanScreen.tsx` to replace native React Native Picker elements.

- **Out of Scope:**
  - Editing plans directly in the history tab (this is handled by the `Generate` stack/editor).
  - Deleting plans from history (unless easily implemented, but let's keep it simple as a read-only list for now).

## Proposed behavior

1. **Navigation Tab:**
   - The Bottom Tab Bar will feature a "History" tab (represented by a book or document history icon) positioned beside the central "Generate" button.
   - We will replace the placeholder "Analytics" tab with the "History" tab as it makes the most sense for the current primary features of Lessora AI.
   
2. **History Screen:**
   - A clean header matching the app's brand.
   - A search input with a magnifying glass icon to filter list items in real-time.
   - A list of history cards showing the title, subject, grade level, duration, and the date it was last updated.
   - When no matching plans are found or there is no history, a premium-looking empty state illustration/message is displayed.
   - Pull-to-refresh to fetch updated lists.

3. **Responsive Modal Grade Selector:**
   - In `GeneratePlanScreen.tsx`, tapping the grade level field opens a slide-up `<Modal>` containing a scrollable lists of grades. Selected options are marked with a checkmark.

## Acceptance criteria

- [x] A dedicated History tab is visible in the bottom tab bar, next to the central Generate button.
- [x] Users can see all previously generated lesson plans in a list on the History screen.
- [x] Users can filter lesson plans by typing into the search bar (filtering by title, subject, or grade level).
- [x] Tapping a lesson plan in the history list navigates the user to the detailed preview/editor screen for that plan.
- [x] The UI matches the existing professional design system (fonts, shadows, colors).
- [x] Grade selection dropdown is fully responsive across all iOS/Android smartphone screen size configurations, using custom modal sheets instead of native wheel selectors.

## Constraints

- **Technical:** React Native (Expo) with NativeWind (Tailwind CSS) and TypeScript.
- **API:** Must use the existing `listRecentLessonPlans` service endpoint.
