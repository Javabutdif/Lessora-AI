# Archiona Pre-Coding Gate

Before writing any code, follow the Archiona workflow defined in `.archiona/workflow.md`.

1. Read `.archiona/workflow.md`.
2. Find or create a plan at `.archiona/plans/<slug>.md`.
3. Fill every section: Evidence, Problem, Files, Dependencies, Test plan, Rollback.
4. Tick `- [x] **Approved**`.
5. Read the matching skill under `.archiona/skills/`.
6. Implement against the approved plan. Only the files listed in the plan.
7. Run `archiona validate` before declaring done.
